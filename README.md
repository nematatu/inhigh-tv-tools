# inhigh-tv-tools

インハイTVの視聴と個人利用のアーカイブ管理を補助する、非公式ツール集です。

## 内容

### `downloader/`

2026年インターハイ・バドミントンの長尺アーカイブを、外付け物理HDDへMP4として保存するmacOS向けスクリプトです。

- 対象日を `--date` で1日または複数日指定
- `--interactive` で日付とコート番号をキーボード操作で複数選択
- `--court` で1コートまたは複数コートに限定
- `--date` 省略時は2026年7月23〜27日の全日程
- 現在の掲載件数は23日36本・24日16本・25日36本・26日36本・27日8本
- 最大1080p
- 1〜36本の並列ダウンロード
- 各動画の進捗率・残り時間・推定完了時刻と「準備中／ダウンロード＋MP4作成中／検証中／完了」をTerminalの固定領域へ表示
- 並列ダウンロード全体の進捗率・残り時間・推定終了日時も同じ領域で更新し、完了・失敗などの確定結果だけを履歴へ残す
- HTTP読取は30秒でタイムアウトしてセグメントを再接続し、180秒進捗がなければffmpegを安全に終了
- 停滞した動画は1回自動再試行し、それでも失敗した場合は記録して残りの動画を継続
- Ctrl+Cは重複送信せず、MP4確定を最大30秒待ってから段階的に停止
- 外付けHDD上の完成済みMP4を検証し、選択肢から自動除外
- 一時ファイル、ログ、状態ファイルも外付けHDD内へ保存
- 保存フォルダ名はASCIIのみの `inhigh-tv-2026-badminton`
- 旧版の日本語名フォルダは、実際のダウンロード開始時に途中ファイルごとASCII名へ自動移行
- 内蔵ストレージへのフォールバックを拒否

必要なもの：macOS、Python 3、FFmpeg / FFprobe。

日本語ヘルプを表示する場合:

```bash
cd downloader
./download_inhigh_2026.command help
```

`-h` または `--help` でも同じ内容を表示します。

日付とコートを画面で選ぶ場合:

```bash
cd downloader
./download_inhigh_2026.command --interactive
```

選択画面では `j` / `k` または上下矢印で移動し、`Space` で複数選択、`Enter` で確定します。`a` は全選択・全解除、`q` はキャンセルです。完成済みMP4は候補に表示されません。

進捗率は、`ffmpeg` が処理した動画時間を全体の再生時間で割った目安です。残り時間と終了予定は、実行中に得られる各並列ジョブの実測速度から随時再計算します。回線速度や配信サーバーの状態によって変動します。HLSの取得とMP4化は `ffmpeg` が同時に処理します。

引数だけで指定する場合:

```bash
cd downloader
./download_inhigh_2026.command \
  --volume '/Volumes/HDDの名前' \
  --date 2026-07-23 \
  --court 1 \
  --court 2 \
  --jobs 12
```

確認だけ行う場合は `--check-only` を追加します。このモードでは動画・状態ファイル・フォルダを書き込まず、旧フォルダ名も変更しません。

### `inhigh-tv-skip-extension/`

インハイTVのStreaks Playerへ「戻る」「進む」ボタンとキーボード操作を追加する、Chrome / Edge向けManifest V3拡張機能です。

- 初期値10秒、1〜300秒で変更可能
- 5・10・15・30秒プリセット
- `←` で戻る、`→` で進む
- `Space` で再生／一時停止
- 全画面対応
- 広告表示中は本編の再生位置を変更しない

導入手順は [`inhigh-tv-skip-extension/README.md`](inhigh-tv-skip-extension/README.md) を参照してください。
