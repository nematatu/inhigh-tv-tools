# インハイTV スキップ操作

インハイTVのStreaks Playerに、秒数指定可能な「戻る」「進む」ボタンとキーボード操作を追加するChrome / Edge向けManifest V3拡張機能です。

## 機能

- 再生ボタンの右側に、戻る・進むの矢印ボタンを追加
- 初期値は10秒（1〜300秒で指定可能）
- `←` キーで戻る、`→` キーで進む
- `Space` キーで再生／一時停止
- 5・10・15・30秒のプリセット
- 全画面表示でも動作
- 入力欄、スライダー、プレイヤー設定メニューの操作中はキーボードショートカットを横取りしない
- 広告表示中は本編の再生位置を変更しない

## Chromeへの追加方法

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. この `inhigh-tv-skip-extension` フォルダを選択します。
5. インハイTVのアーカイブ画面を再読み込みします。

拡張機能のアイコンを押すと、スキップ秒数とキーボード操作の有効・無効を変更できます。

## 対象サイト

- `https://inhightv.sportsbull.jp/*`

2026年7月27日時点のインハイTV・アーカイブ画面にあるStreaks PlayerのDOM構造で確認しています。サイト側のプレイヤー構造が変更された場合は、セレクターの調整が必要になる可能性があります。
